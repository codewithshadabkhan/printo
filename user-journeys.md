# User journeys

Evidence codes and links: `functional-spec.md`. For every reference journey, browser state transitions, validation and network payloads remain **U** unless explicitly supported by page text. The following steps describe the implemented **L** journey. No reference state was modified.

| Journey / step | Starting state → action               | Validation                                      | State change / success                             | Failure outcome                                                 | Next route / request                          |
| -------------- | ------------------------------------- | ----------------------------------------------- | -------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------- |
| Category 1     | Home → choose category                | Selected local route exists                     | Category assortment                                | Not-found for unknown path                                      | Category document; reference category links O |
| Category 2     | Category → price band/sort            | Allowed URL values                              | Count/grid and URL update                          | Empty matching section                                          | Same route; no API                            |
| Category 3     | Filtered list → select product        | Product exists                                  | Configuration URL loaded                           | Unknown product shows not-found                                 | Product path; Back restores listing URL       |
| Search 1       | Header → type query                   | ≤200 characters                                 | Up to five local suggestions                       | No suggestions; normal submission still available               | No network                                    |
| Search 2       | Submit / keyboard choose              | Search terms normalised                         | Result count/filter/sort or product                | Empty/no-result message                                         | /search?q=… or product                        |
| Search 3       | Results → filter → product → Back     | Allowed filters/sort                            | Original URL-driven state restored                 | Invalid URL choices normalised                                  | No private ranking inferred                   |
| Configure 1    | Product default/query → select option | Central allowed values                          | Dependency resets with notice; URL replaces config | Unsupported service input rejected                              | Same route                                    |
| Configure 2    | Config change → price request         | Valid combination                               | Latest quote shown; actions enabled                | Visible retry; stale/cancelled response ignored                 | quoteService, no HTTP                         |
| Design 1       | Product → gallery → preview           | Local product/template                          | Original design preview/name                       | Unknown template falls back to sample                           | /…/templates and /editor                      |
| Design 2       | Editor → text/colour/side/font edits  | Text lengths, colour/font allowlists            | Front/back/history changes                         | Invalid documents rejected                                      | Component state                               |
| Upload         | Editor → select image                 | PNG/JPEG/WebP, size/signature/decode/dimensions | Browser-local raster preview                       | Specific validation/read error; no upload occurs                | FileReader only; reference flow U             |
| Design 3       | Image → zoom/rotate/position          | Bounded transforms                              | Clipped preview; warning for low resolution        | Unsupported/corrupt image rejected                              | No network                                    |
| Design 4       | Save → resume → preview               | Valid document, writable storage                | Local draft restored, both faces visible           | Storage error; preview never called print-ready                 | /editor?product=…&resume=1                    |
| Cart 1         | Product/designed sample → add         | Valid config/design, capacity                   | Canonical merge or distinct line                   | Limit/config/storage feedback; duplicate burst ignored          | Local shared state                            |
| Cart 2         | Cart → sets/edit/remove               | Integer sets 1–99, central config               | Reprice, possibly merge, or empty cart             | Invalid edit/over-limit merge shown                             | /c/                                           |
| Cart 3         | Cart → apply/remove coupon            | Code/minimum/scope/expiry/cap                   | Savings and total recomputed                       | Error; invalid applied code blocks checkout                     | Local coupon function                         |
| Account        | Guest → demo sign-in                  | No credentials; session store writable          | Demo alias/30-min session; same guest cart         | Explicit guest fallback                                         | /my-account/                                  |
| Checkout 1     | Cart → mock checkout                  | Non-empty cart                                  | Guest or demo account choice                       | Empty cart screen                                               | /checkout                                     |
| Checkout 2     | Select/edit fictional address → check | Required fields/PIN/mobile                      | Session address and local delivery choices         | Inline errors, unserviceable PIN, retry/cancel                  | deliveryService                               |
| Checkout 3     | Select delivery/payment → acknowledge | Current PIN option; enum only                   | Reviewed total and confirmation action             | Cart changes clear acknowledgement; invalid coupon blocks       | No card fields                                |
| Checkout 4     | Confirm once                          | Revalidate cart/session/address/coupon/delivery | Persist local confirmation, then clear cart        | Error retains cart; retry uses same intent; stale cart rejected | placeOrder → /order-confirmation?id=…         |
| History        | Confirmation → history → reorder      | Current item validity/limits                    | Snapshot display; current-price items added        | Unavailable lines skipped with explanation                      | /my-account/orders → /c/                      |

Reference evidence: E1 supports the configuration/design entry surfaces, E2 supports template filter labels, E3 supports only a cart shell, E4 supports history/reorder navigation. Original sign-in, address, checkout, upload, confirmation and reorder outcomes could not be inspected and are not claimed to match.
