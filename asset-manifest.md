## Original replacement inventory

Generated by scripts/generate-assets.mjs, stored in public/assets: cards.svg, polo.svg, shirt.svg, tshirt.svg, hoodie.svg, stamp.svg, poster.svg, flyer.svg, stickers.svg, packaging.svg, notebook.svg, mug.svg, album.svg, tote.svg, bottle.svg, cap.svg, folder.svg, pen.svg, banner.svg, frame.svg. Each has a 600×750 viewBox and is self-contained. They use invented brands and abstract artwork; no reference image is traced.
Inline icons in src/components.tsx are original line paths with a 24×24 viewBox. Template designs in src/data.ts/src/App.tsx are original CSS compositions. Images have aspect-ratio containers and contain/crop rules in src/styles.css. Replacements differ materially from reference photography and must remain listed as a fidelity limitation.

The original favicon in public/favicon.svg uses a simple letterform and is not a reference brand asset. Generic merchandise previews combine the original product SVG with an identity label; they are not print proofs.

Phase 4 adds `public/assets/image-unavailable.svg`, an original fallback illustration. User-selected editor raster files are read locally only, limited to permitted PNG/JPEG/WebP files up to 512 KiB. Their rights are the user's responsibility; no image is transmitted to the reference or another service. Draft/cart image persistence can hit browser storage quota and is not a print-export pipeline.
